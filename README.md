# claude-skills

Siam's Claude Code skills, packaged as a plugin marketplace.

## Install

```
/plugin marketplace add EhsanulHaqueSiam/claude-skills
/plugin install siam-skills@siam
```

## What's inside

A flat collection (~92 skills) — no pipeline; each skill is invoked individually
by its trigger:

- **Design & frontend taste** — apple-design, minimalist-ui, industrial-brutalist-ui,
  design-taste-frontend, high-end-visual-design, emil-design-eng, brandkit, …
- **Animation** — animate, improve-animations, review-animations, transitions-dev,
  transitions-polish, find-animation-opportunities, …
- **SEO toolkit** — seo, seo-audit, seo-page, seo-plan, seo-technical, seo-schema,
  seo-local, seo-programmatic, …
- **Platform** — cloudflare, workers-best-practices, durable-objects, wrangler,
  electron, shadcn, supabase/react/auth best-practice packs, …
- **Workflow utilities** — html-communication, babysit-pr, file-pr, diagnose-crash,
  skill-creator, orchestration, …

Browse `plugins/siam-skills/skills/*/SKILL.md` — each description states when it
triggers.
